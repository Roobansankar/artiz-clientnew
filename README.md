# Artiz – Interior Design Studio (Next.js)

Next.js App Router + Tailwind CSS v4, Swiper and framer-motion.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

- `src/app/` – routes: `/` (home) and `/shop`, plus the root layout (header, footer, cart drawer, popups)
- `src/sections/`, `src/components/`, `src/views/` – UI (client components)
- `src/data.js`, `src/shopData.js` – static content
- `public/` – images and video
That’s warm ivory, a pale beige with a slight pink tint—approximately #F6F0EC# artiz-clientnew
